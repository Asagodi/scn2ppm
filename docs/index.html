Spike coding networks as piecewise projective maps

Rotatable versions of the figures. Drag to turn the scene, scroll to zoom, and click a legend entry to hide a trace.

Orbits in three dimensions

  • Simon sequence RBYGYB

    The period-6 orbit of Figure 5 on a four-neuron, three-dimensional network, with the four spike bounds and the spike-and-decay path between them.

  • Chirality multistability

    Two period-3 orbits coexisting at one parameter setting, related by swapping neurons 2 and 3, with the initial state deciding which one is reached.

  • Line attractor, orbit family

    The degenerate case in which the isolated orbit gives way to a one-parameter family sharing a single firing word.

  • Line attractor, causal view

    The same construction followed spike by spike, showing which bound is reached at each step.

Parameter sweeps

  • Decoder angle sweep

    How the orbit and the firing ratio move as one decoder is rotated.
